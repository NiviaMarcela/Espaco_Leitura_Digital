# Espaco_Leitura_Digital
Projeto Let's Code para o Instituto Janela para o Mundo

## Livro Vivo — 15/11/2026

Novo menu exclusivo de administrador e coordenador para transferir exemplares às escolas e comunidades, com baixa automática, histórico e modalidades Definitiva ou Com possibilidade de devolução. A segunda modalidade permite retorno parcial à estante. Consulte [o guia do Livro Vivo](backend/GUIA-LIVRO-VIVO.md) para fluxo, permissões e testes. Em outros ambientes, aplique a migração 013 com `npm run db:migrate` no backend antes de usar.
